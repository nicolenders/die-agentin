# Architekturentscheidungen

Ein Eintrag je Entscheidung, fortlaufend nummeriert. Kurz halten:
Kontext, Entscheidung, Begründung, Konsequenzen.

Neue Einträge nach dem Muster `NNNN-kurzer-titel.md`.

Jeder Eintrag beginnt mit `**Datum:**` und `**Status:**`. Eine Nummer wird genau
einmal vergeben — beides prüft `lib/docs/decisions.test.ts`, nachdem 0015 eine
Zeit lang doppelt belegt war und Verweise darauf mehrdeutig wurden.

Den Rahmen, in dem diese Entscheidungen zusammenpassen, beschreibt
`docs/ARCHITEKTUR.md`.
